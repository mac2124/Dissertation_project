This zip file contain the following folders:
| Folder | Description | 
|---|---|
| Confounding_variable_Datasets | These are the datasets that where used to conduct the confounding variable tests
| Corpus | The curated corpus used for H1 and generation of visualisation seen in the main pdf
| Custom Model Training | A folder containing the code, dataset, dockerfile and requirements.txt file that where used duing the custom model training on the university hex cloud.
| H1 Results | Full detailed data generated form the Hypothesis 1 experiments
| H3 Results |  Full detailed data generated form the Hypothesis 3 experiments
| Main Pipeline | Includes the code for the main pipeline, a readme file describing the code and how to run it as well as a requirements.txt file detailing all the dependencies needed to run it.
| Validation_dataset | The full dataset used in the H2 experiments

Note: Full experimental results for H2 are detailed in the appendix of the PDF and are therefore excluded from this sumbission.
